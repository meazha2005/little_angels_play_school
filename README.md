# LITTLE ANGELS PLAY SCHOOL — Website

A modern, light-themed, mobile-first website for **LITTLE ANGELS PLAY SCHOOL**, Kundrathur, Chennai. Built with Next.js 14 (App Router), TypeScript, and Tailwind CSS, featuring smooth scrolling, interactive gallery with lightbox, and direct WhatsApp & Call integration.

---

## 🌟 Key Features

- **Logo-Matched Theme**: Handcrafted palette based on the official school logo (Vibrant Magenta-Pink `#E11D74`, Warm Sunshine Gold `#F59E0B`, Sky Blue `#0284C7`, Mint Green on crisp, warm white surfaces).
- **Early Childhood Focus**: Built exclusively for children aged 1.5 to 6 years old.
- **Programs & Classes**:
  - **PlayGroup** (1.5 – 2.5 Years)
  - **Pre-KG** (2.5 – 3.5 Years)
  - **LKG** (3.5 – 4.5 Years)
  - **UKG** (4.5 – 5.5 Years)
- **Pages Included**:
  1. **Home (`/`)**: Hero banner, pillars of care, program previews, photo highlights, testimonials, CTA banner.
  2. **About Us (`/about`)**: School philosophy, vision & mission, safety standards (CCTV, hygiene, first-aid), KG convocation feature.
  3. **Classes (`/classes`)**: In-depth curriculum, developmental milestones, daily routine schedule, and age eligibility guide.
  4. **Gallery (`/gallery`)**: Filterable photo albums (Graduation Day, Festivals & Culture, Class Activities & Fancy Dress) with interactive modal Lightbox.
  5. **Contact Us (`/contact`)**: Direct call (`+91 9962485335`), WhatsApp chat, admission inquiry form with WhatsApp redirection, Kundrathur Google Maps embed, and FAQ accordion.
- **Mobile-Responsive & Smooth**: Fast sticky navigation with mobile drawer, floating quick action buttons for WhatsApp and Phone call.
- **Zero Server Bugs**: 100% type-safe, statically prerendered with Next.js for instant page loads.

## 🚀 Getting Started Locally

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.

### 2. Build for Production
```bash
npm run build
npm run start
```

---

## ☁️ Deploying to Vercel

1. Push this repository to GitHub or GitLab.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository.
4. Framework preset will automatically detect **Next.js**.
5. Click **"Deploy"**. The site will build and be live worldwide in seconds!
